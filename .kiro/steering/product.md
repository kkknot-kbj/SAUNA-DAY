# SAUNA DAY — プロダクト思想

## 一行で言うと

**サウナの質で「一棟貸しの宿」を選べる、唯一の場所。**

メインコピー：

> サウナで選ぶ、
> 一棟貸しの休日。

## 解く課題

サウナ目的で一棟貸し・貸別荘に泊まりたいのに、探すのがとても大変。

- Airbnb / 一休 / じゃらん は「宿」の検索であって、**サウナの質で引けない**
- 「常設サウナか、テント貸出か」「貸切か」「水風呂・川に入れるか」「薪か電気か」が既存の宿検索では**一つも分からない**
- 結局、写真を1件ずつ開き、Instagram や個人ブログを漁ることになる

## 競合と、勝てる隙間

サウナ付き宿泊の情報を集めた先行サービスは存在する（ACO、タビルモ、SaunaTrip 等）。
だが、それらは **貸別荘サイトの一機能としてサウナを扱っており、サウナの中身の解像度が低い**。
「サウナがどれだけ本格的か」で選べる場所はまだない。UIも旅行予約サイト然としている。

**勝てる隙間 = サウナの質の解像度 × 綺麗なUI。**
競合は「宿サイトにサウナ情報が付いている」。うちは「サウナ視点で一棟貸しを選べる」。視点が逆。

## 主役は「サウナ付き一棟貸し」

ユーザーは「サウナに入れる貸別荘に泊まりたい」と思ってこのアプリを開く。
このアプリは、その宿を **サウナの質（サウナタイプ・熱源・クールダウン・貸切性・外気浴）** で探せるようにする。

**IMPORTANT: 一般的な貸別荘予約サイトになってはいけない。** 立地や価格で並べるだけなら ACO や Airbnb に勝てない。「サウナがどれだけ良いか」で選べることが唯一の存在理由。

**IMPORTANT: ホテル・カプセル・日帰り施設は主役にしない。** 対象は一棟貸し・貸別荘・グランピングなど、貸切で泊まれるサウナ付き施設。

判断に迷ったら「サウナ目的で一棟貸しに泊まる人の、宿選びが良くなるか？」を基準にする。

## サウナの質を、宿検索で初めて引けるようにする

既存の宿検索が持たない、サウナの一次情報を構造化して持つ：

| 軸 | 例 |
|---|---|
| サウナタイプ | 常設 / テント / バレル / 小屋 |
| 熱源 | 薪 / 電気 / ガス |
| クールダウン | 水風呂 / 川に入れる / 湖 / 天然水 / なし |
| 貸切性 | 1棟貸し貸切 / 時間貸切 / 共用 |
| 外気浴 | 川沿い / 星空 / 絶景 / インフィニティ |

**IMPORTANT:** 「川が見える」と「川に入れる」を必ず分ける。宿の売り文句に流されず、実際に何ができるかを正確に表す。

## IMPORTANT: AIを前面に出さない

AIは裏側の補助（翌日の過ごし方の提案など）だけに使う。ユーザー体験の主役ではない。

以下は**すべて禁止**：

- 「AIがおすすめします」等のAI言及コピー
- AIチャット画面 / チャットUI
- 「✨あなたにぴったり✨」のような煽り表現
- キラキラした演出、魔法っぽいローディング
- 「生成中...」など生成AIを想起させる文言

宿検索は**AIに行わせない**。DBに対する検索・フィルタ・ランキングで実現する。

## 予約は握らない、送客する

**IMPORTANT: 自前の予約・決済システムを作らない。** 予約基盤（Airbnb / 一休 / じゃらん / 施設独自）は既に飽和しており、後発が握るのは筋が悪い。

このアプリの価値は「予約を持つこと」ではなく「**サウナで宿を選べること**」。
予約は各施設の予約ページ（外部）へ送客する。予約URLはDBに保持する。
将来のマネタイズは送客手数料（アフィリエイト）を想定する。

## ユーザーに感じてほしいこと

目指す反応：

- 「サウナ付きの一棟貸し、これでやっと探せる」
- 「サウナの中身がちゃんと分かる」
- 「Airbnbやゴチャついた予約サイトで消耗してたのがバカらしい」

避けたい反応：

- 「よくある貸別荘予約サイトだ」
- 「AIアプリだ」

## 会員登録の扱い

**閲覧・検索に会員登録は不要。** 最初から登録を要求しない。

登録を求めるのは「行きたい」を保存するときだけ。
ゲスト状態では検索条件や直近閲覧を端末側に一時保存し、登録後にアカウントへ移行する。

## MVPのスコープ

含む：探す / 条件設定（サウナの質 + 宿の枠）/ 検索結果 / 宿詳細 / 行きたい / 認証

含まない：
- **予約・決済そのもの**（各施設の予約ページへ遷移するのみ。予約URLはDBに保持）
- メールアドレス・パスワード認証（Apple / Google のみ）
- レビュー・口コミ投稿
- 地図上での検索
- 休日プラン生成（コードは残すが、当面は表に出さない。「泊まった翌日どうする」のオマケに縮小しうる）

## 過去の方向性からの転換（記録）

当初は「サウナを起点に休日プラン（サ飯・観光・宿泊）を組む」プロダクトだった。
一次情報（自分自身が Airbnb でサウナ付きの一棟貸しを探すのが最も大変だった）と、
競合調査（ACO 等はサウナの解像度が低く UI も古い）に基づき、
**「サウナ付き一棟貸しの検索」に主役を絞った。** 休日プラン機能は主役から降ろした。

## 開発フェーズ

| Phase | 内容 |
|---|---|
| 済 | 検索・フィルタ基盤 / サウナタグ / 認証 / DB |
| 転換 | プロダクトを「サウナ付き宿」に再定義 |
| 次 | 宿データへの差し替え / 宿詳細の再設計 / 予約導線 |

**最初からすべてを完成させようとしない。** まず「Airbnbより探しやすい」と自分が思えるかを検証する。
