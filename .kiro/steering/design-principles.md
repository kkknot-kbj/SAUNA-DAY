# UI / UX 規範

目指すのは **洗練されたアウトドアブランド**。自然 / 静か / 上質。
写真を主役に、余白を大切に、タイポグラフィで語る。

## IMPORTANT: 禁止事項

実装時に以下を作ってはいけない。レビューで見つかったら差し戻す。

| 禁止 | 代わりに |
|---|---|
| **絵文字をアイコンとして使用**（🔥💧🌿 等、iPhone標準絵文字を含む） | `lucide-react` の線画アイコン |
| 過剰な絵文字（本文・ラベル・ボタン） | テキストのみ、またはアイコン |
| 過剰なグラデーション | 単色。写真の上のオーバーレイのみ例外 |
| AIっぽいキラキラUI（グロー、パーティクル、虹色） | 静的で落ち着いた表現 |
| 大量のカード（画面を埋め尽くすカードグリッド） | リスト + 十分な余白。1画面の情報量を絞る |
| 過剰な丸角（`rounded-xl` 以上、pill型ボタン） | 2〜4px。下記トークン参照 |
| 説明文だらけの画面 | 見出し + 最小限の補足。詳細は開示で隠す |
| ドロップシャドウの多用 | 罫線（1px）で区切る |

## デザイントークン

### 配色

モノトーンをベースに、自然を感じるアクセントを1色だけ差す。

```
/* ベース（無彩色・やや暖色寄り） */
--color-ink        #16181A   /* 本文・見出し */
--color-ink-muted  #5C6166   /* 補足テキスト */
--color-ink-faint  #9AA0A6   /* プレースホルダ・非活性 */
--color-line       #E3E1DD   /* 罫線 */
--color-surface    #F7F6F3   /* 背景（紙のような白） */
--color-base       #FFFFFF   /* カード面 */

/* アクセント：杉（深い緑）— 1色のみ */
--color-accent       #3A4A3F
--color-accent-hover #2C3931
--color-accent-weak  #EDF0EC   /* 選択中チップの背景 */
```

- アクセントは「選択中の状態」「主要CTA」だけに使う。装飾に使わない
- 赤は破壊的操作とエラーのみ（`#8C3A2E`）
- **カラーはCSS変数経由で参照する。コンポーネントに16進数を直書きしない**

### 角丸

```
--radius-sm  2px   /* チップ、タグ、入力 */
--radius-md  4px   /* カード、ボタン、シート */
```

これ以外の角丸を使わない。円形は avatar とアイコンボタンのみ許可。

### タイポグラフィ

| 用途 | フォント | 補足 |
|---|---|---|
| ヒーローコピー、施設名（詳細） | **Noto Serif JP** | 明朝で編集的な静けさを出す |
| UI全般、本文、ラベル、数値 | **Noto Sans JP** | |

- 行間は本文 1.8、見出し 1.4 を基準に広めをとる
- 数値（料金・所要時間・一致率）は `tabular-nums` を当てて桁を揃える
- 見出しは大きさより**余白**で階層をつくる

### 余白

4px グリッド。セクション間は 32px 以上あける。詰め込まない。

## 情報の優先順位

各画面で「ユーザーが今いちばん知りたい1つ」を決め、それを最も大きく置く。

- 検索結果 → **写真** と **条件一致率**
- サウナ詳細 → **写真** と **このサウナで休日を作る**
- 休日プラン → **時系列**

補足情報は Disclosure（「条件を追加」「詳細を見る」）で隠す。
**最初から大量の条件・情報を並べない。**

## IMPORTANT: 必須 / 希望はタグ単位

ユーザーの頭の中は「川は絶対、薪なら嬉しい」のように**タグ単位**で強さが違う。
カテゴリごとに必須・希望を固定してはいけない。

`Chip` は3状態を持つ。タップで 未選択 → 希望 → 必須 → 未選択 と循環する。

| 状態 | 見た目 | 検索での扱い |
|---|---|---|
| 未選択 | `border-line` + グレー + カテゴリアイコン | 無視 |
| 希望 | `border-2 border-accent` + `bg-accent-weak` + チェック | 一致数をスコアに加算 |
| 必須 | `bg-accent` の塗り + 鍵 + 「必須」の文字 | 満たさない施設を除外 |

- **状態を色だけで区別しない。** 罫線の太さ・アイコン・文字を併用する
- 3状態は発見されにくいので、操作方法を画面上に1行で示す
- 必須にしているタグは、カテゴリを跨いで一覧できる場所を用意する（`SelectedConditions`）
- 検索結果でも「何を必須にして絞ったか」を出す

必須は施設を除外するので**絞りすぎの主因**になる。0件になったときは必須の解除を最優先で提案する。

## 条件入力は1問1画面

条件は数が多い。1画面に並べると圧迫感が出て離脱する。

- **ホームの条件入力は1問ずつ1画面**で進める（`StartFlow`）
- 選択肢は縦積みの `ChoiceList` を使う。横並びのチップより押し間違いが少ない
- **単一選択のステップは選択後に自動で次へ進む**（260ms 後）。タップ数を半分にできる
- 数値の微調整（人数など）はステップに置かず、最後の確認画面に寄せる
- 日付のような入力コストが高い項目は**プリセットを用意する**（今週末 / 来週末 / 日付を選ぶ）
- 各ステップに「指定せず進む」と「戻る」を必ず置く
- 進捗は 1px の線と「3 / 6」だけ。ステップインジケーターを飾らない
- 最後に確認画面を置き、各項目から該当ステップへ戻れるようにする

### 動きの上限

ステップ遷移は「進んだ」ことを伝えるためだけに使う。演出しない。

- 移動距離 8px、時間 220ms、`ease-out` まで
- 回転・拡大・バウンス・フェード以外の効果を使わない
- **`prefers-reduced-motion: reduce` では動きを止める**

## アイコン

- `lucide-react` のみ。他のアイコンパッケージを追加しない
- ストローク 1.5px、サイズは 16 / 20 / 24 の3種のみ
- タグの意味とアイコンの対応は `src/lib/taxonomy/terms.ts` に集約し、画面ごとに個別指定しない

## 写真

- カードは 3:2、詳細ヒーローは 4:5（縦）を基準
- 写真の上に文字を載せる場合、下方向へのリニアな黒オーバーレイのみ許可（装飾グラデーション禁止）
- `next/image` を使い、`alt` を必ず入れる

## アクセシビリティ

- テキストコントラスト比 4.5:1 以上（大きい文字は 3:1 以上）
- タップ領域は最小 44×44px
- 選択状態を色だけで表さない（罫線の太さやチェックアイコンを併用）
- フォーカスリングを消さない
- 条件チップは `role="checkbox"` 等、適切なセマンティクスを持たせる

## マイクロコピー

- 静かで断定的に。感嘆符とハイパボリックな表現を避ける
- ローディングは「探しています」「休日を組み立てています」。「AI」「生成」は使わない
- 空状態は次の行動を1つだけ示す（例：「まだ保存したサウナはありません」＋「サウナを探す」）
- 不明な情報は正直に「不明」と表示する（詳細は `data-integrity.md`）
